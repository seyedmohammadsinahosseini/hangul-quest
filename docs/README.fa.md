## این پروژه چیست؟

Hangul Quest یک دورهٔ مقدماتی زبان کره‌ای است که از **خط هانگول** شروع می‌کند، بعد واژگان
بقا، بعد گرامر و در نهایت مکالمهٔ واقعی را آموزش می‌دهد؛ به انگلیسی، طراحی‌شده برای موبایل و
بدون نیاز به ثبت‌نام. یک درس فقط وقتی «گذشته» حساب می‌شود که نمره‌ات **≥ ۷۰٪** باشد؛ پس نقشهٔ راه
سندی از چیزهایی است که واقعاً یاد گرفته‌ای، نه چیزهایی که فقط کلیک کرده‌ای.

دو کلاینت وجود دارد که همان برنامهٔ درسی و همان قوانین را به اشتراک می‌گذارند:

| | پوشه | فناوری | ویژگی |
|---|---|---|---|
| **وب** | [`web/`](../web) | Next.js 16 · React 19 · TypeScript · Tailwind 4 · Drizzle ORM · PostgreSQL | پیشرفت سمت سرور، اقتصاد XP، لیدربورد، REST API |
| **موبایل** | [`mobile/`](../mobile) | Flutter 3.27+ · Dart · `shared_preferences` · `flutter_tts` | کاملاً آفلاین، همان ۳۹ درس و همان قوانین |

## قابلیت‌ها

**برنامهٔ درسی — چهار مرحلهٔ قفل‌شده**

| مرحله | مسیر | درس‌ها | چه وقت باز می‌شود |
|---|---|---|---|
| ۱ | مبانی هانگول | ۱۱ | همیشه |
| ۲ | واژگان ضروری | ۱۵ | قبولی در آزمون جامع هانگول (یا ۷۰٪ مرحلهٔ ۱) |
| ۳ | موتور گرامر | ۹ | ۴ درس واژگان با دقت ≥ ۷۰٪ |
| ۴ | مکالمهٔ واقعی | ۴ | ۳ درس گرامر با دقت ≥ ۷۰٪ |

**هشت نوع تمرین** — فلش‌کارت با نمایش معنی، کره‌ای ← انگلیسی، انگلیسی ← کره‌ای، خواندن
رومانیزه، شنیداری (تبدیل متن به گفتار کره‌ای)، تایپ رومانیزه، **سازندهٔ هجا** (چیدن صامت و مصوت
با ریاضیات یونیکد `U+AC00` تا یک بلوک واقعی ساخته شود) و **سازندهٔ جمله** (مرتب‌کردن قطعه‌های
جمله).

**اقتصاد بازی، هدف است نه تزئین**

- **۱ XP برای هر پاسخ درستِ بدون راهنما.** راهنمای کوچک ۶ XP، راهنمای مربی ۱۲ XP و نمایش پاسخ
  ۱۸ XP — و سؤالی که با راهنما جواب داده شود، هیچ XP ندارد. شش پاسخ درست = شش امتیاز؛ شش پاسخ
  غلط = یک راهنما.
- **قانون ۷۰٪ برای عبور** — تلاش دوباره ارزان است، رد کردن مفهوم نه.
- **کارت‌های مرور فاصله‌دار** — کارتی که غلط جواب داده شود برمی‌گردد تا سه بار پشت‌سرهم درست
  یادآوری شود، بعد بازنشسته و «تسلط‌یافته» علامت می‌خورد.
- هدف روزانه و استریک (با یک روز فرصت)، ۸ دستاورد، لیدربورد و پوستهٔ روشن/تیره.

## ساختار ریپو

```
.
├── web/                  اپلیکیشن Next.js (سرور + کلاینت)
│   ├── src/app/          صفحات App Router و هندلرهای REST
│   ├── src/lib/          curriculum.ts · quiz.ts (تولید سؤال) · engine.ts (قوانین XP)
│   ├── src/db/           شِمای Drizzle و اتصال دیتابیس
│   ├── drizzle/          مایگریشن‌های SQL (کامیت‌شده)
│   └── tests/            تست‌های Vitest برای برنامهٔ درسی و تولید سؤال
├── mobile/               اپلیکیشن Flutter (آفلاین)
├── docs/                 معماری · نقشهٔ راه · دیپلوی · اسکرین‌شات‌ها
└── .github/workflows/    CI: lint، typecheck، test، build
```

## اجرا — وب

نیازمند **Node 20+** و یک دیتابیس **PostgreSQL**.

```bash
git clone https://github.com/seyedmohammadsinahosseini/hangul-path.git
cd hangul-path/web

cp .env.example .env          # DATABASE_URL را به دیتابیس خودت وصل کن
npm install
npm run db:migrate            # اعمال مایگریشن‌های کامیت‌شده
npm run db:seed               # اختیاری: پروفایل نمونه + دادهٔ لیدربورد
npm run dev                   # http://localhost:3000
```

| دستور | کار |
|---|---|
| `npm run dev` / `build` / `start` | سرور توسعه، بیلد پروداکشن، سرور پروداکشن |
| `npm run test` | تست‌های Vitest (یکپارچگی برنامهٔ درسی، قوانین XP، تولید سؤال) |
| `npm run lint` · `npm run typecheck` | ESLint · `tsc --noEmit` |
| `npm run db:generate` · `db:migrate` · `db:push` | مایگریشن‌های Drizzle Kit |
| `npm run db:seed` | درج پروفایل نمونه |

## اجرا — موبایل

نیازمند **Flutter 3.27+**.

```bash
cd mobile
flutter create . --project-name hangul_quest --org com.hangulquest --platforms android,ios
flutter pub get
flutter run                   # یا: ./setup.sh که همین دو کار + مجوز TTS را انجام می‌دهد
```

اپ Flutter نسخهٔ خودش از برنامهٔ درسی را دارد و بدون هیچ اینترنتی کار می‌کند؛ پیشرفت در
`shared_preferences` ذخیره می‌شود.

## API

| مسیر | متد | کار |
|---|---|---|
| `/api/state` | `GET` | کل وضعیت زبان‌آموز: پروفایل، پیشرفت هر مسیر/درس، کارت‌های مرور، دستاوردها |
| `/api/state` | `POST` | ساخت/به‌روزرسانی پروفایل |
| `/api/action` | `POST` | `lesson` · `review` · `hint` · `profile` · `reset` — تنها راهی که XP حرکت می‌کند |
| `/api/leaderboard` | `GET` | رتبه‌بندی بر اساس XP با دقت و رتبهٔ خودت |
| `/api/health` | `GET` | بررسی سلامت دیتابیس |

## تست و CI

```bash
cd web && npm run test        # ۱۳ تست: یکپارچگی idها، نمرهٔ عبور، قطعیت RNG، گزینه‌های غلط
```

`.github/workflows/ci.yml` روی هر push و هر Pull Request اجرا می‌شود: lint، typecheck، تست‌ها و
بیلد پروداکشن.
